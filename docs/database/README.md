## 二、dbdiagram.io 复现步骤

1. 打开 <https://dbdiagram.io/d>。
2. 清空左侧默认示例，粘贴 `dbml/class_test_full.dbml` 的全部内容。
3. 右侧自动生成 ER 图；使用右上角 **Export → PNG/PDF** 可导出图片。
4. 表分组（TableGroup）对应六个主题域；关系线由 `Ref` 定义。
5. 修改字段时先改 DBML，再同步 `sql/` 与 Excel，保持三处一致。

## 四、物理建表与数据持久化（Oracle 已落地）

物理建表**不是手写 DDL**，也不是 Hibernate 自动建表，而是由 dbdiagram.io 从 DBML 导出 SQL 后执行：

```text
docs/database/dbml/class_test_full.dbml
        │  dbdiagram.io 网页 Export → SQL（Oracle 方言）
        │  或 npx @dbml/cli dbml2sql ... --oracle
        ▼
sql/dbdiagram-export/dbml_export_oracle.sql
        │  类型适配为 Oracle 原生：bigint→NUMBER(19)、text→CLOB、
        │  varchar→VARCHAR2、GENERATED AS IDENTITY→GENERATED BY DEFAULT AS IDENTITY
        ▼
backend/src/main/resources/db/schema-dbml-oracle.sql
        │  首次启动由 OracleSchemaBootstrapRunner 执行（ddl-auto=none）
        ▼
Oracle FREEPDB1 的 LIFE_CIRCLE schema（27 张表、41 个外键）
```

H2 文件库链路保留为离线回退：`dbml_export_postgres.sql` → 去掉 `DEFERRABLE` → `schema-dbml-h2.sql`。

持久化代码位于后端：

- `backend/src/main/java/com/lifecircle/domain/*.java`：27 张表对应的 JPA 实体；
- `backend/src/main/java/com/lifecircle/repository/*Repository.java`：27 个 Spring Data JPA 仓储；
- `backend/src/main/java/com/lifecircle/config/OracleSchemaBootstrapRunner.java`：Oracle 首次启动执行建表脚本；
- `backend/src/main/java/com/lifecircle/config/SchemaBootstrapRunner.java`：H2 回退时执行建表脚本；
- `backend/src/main/java/com/lifecircle/service/PersistenceDemoRunner.java`：向各表写入演示数据并输出行数；
- `backend/src/main/resources/application.yml`：Oracle 读写分离 + `ddl-auto=none`（`app.datasource.mode=oracle` 为默认）；
- `backend/src/main/resources/application-h2.yml` / `application-h2file.yml`：离线回退配置（`app.datasource.mode=h2`）。

运行与持久化验证：

```powershell
# 默认即 Oracle（application.yml 中 app.datasource.mode=oracle）
mvn -f backend/pom.xml spring-boot:run

# 建表 + 写入 + 读回
mvn -f backend/pom.xml spring-boot:run "-Dspring-boot.run.profiles=demo" `
  "-Dspring-boot.run.arguments=--spring.main.web-application-type=none --persistence.exit-after-demo=true"

# 无 Oracle 环境时回退：h2（内存）或 h2file（文件库），可与 demo 叠加
mvn -f backend/pom.xml spring-boot:run "-Dspring-boot.run.profiles=h2file,demo" `
  "-Dspring-boot.run.arguments=--spring.main.web-application-type=none --persistence.exit-after-demo=true"
```

实测结果（Oracle AI Database 26ai Free，FREEPDB1）：27 张表由 dbdiagram.io 导出的脚本创建；进程重启后行数不变；`POST /api/merchant/intents` 写入的记录在重启后仍存在。详见 `sql/10_oracle_persistence_verification.txt`。单元测试使用 `backend/src/test/resources/application.yml` 的 H2 内存库，不依赖 Oracle。

## 五、设计口径

- 结构化业务数据统一放 DWD；原始接口报文保留在 ODS；评分排名等派生结果放 ADS 快照。
- 时间统一存 UTC，展示层按 Asia/Shanghai 转换。
- 手机号只存 SHA-256 哈希；商户联系方式 AES-256-GCM 加密后 Base64 存储，列表用脱敏字段。
- 枚举值中文与前端 `docs/DATA_CONVENTIONS.md` 逐字一致；英文状态码用于内部流转。
- 大表按时间分区，ODS 按月分区并压缩；索引与数据分表空间存放。
